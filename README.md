# CyberShield Analyzer

A lightweight client-side web security tool built using HTML5, CSS3, and JavaScript.

## Features
- **Password Strength Analyzer:** Evaluates password complexity in real time based on length, uppercase letters, numbers, and special characters.
- **Phishing URL Heuristic Scanner:** Flags suspicious URL patterns such as unencrypted `http://`, `@` symbol redirection tricks, raw IP-based hosts, excessive phishing keywords, and unusually long URLs.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
